## 写在前面

这篇笔记的结构都一样：**先给 Markdown 原文**（灰底那一块，不会被渲染），**再给渲染结果**。

忘了某个语法怎么写的时候，翻到这里照着抄即可。

## 一、标题

**原文**：

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

**效果**：

# 一级标题

## 二级标题

### 三级标题

#### 四级标题

一共六级，`#` 越多级别越低。不过正文里一般从二级开始用，一级留给文章标题。

## 二、文字样式

**原文**：

```markdown
普通文字，**加粗**，*斜体*，***加粗斜体***，~~删除线~~。
行内代码用反引号：`console.log("hi")`。
需要原样输出符号时加反斜杠：\*这不是斜体\*。
```

**效果**：

普通文字，**加粗**，*斜体*，***加粗斜体***，~~删除线~~。
行内代码用反引号：`console.log("hi")`。
需要原样输出符号时加反斜杠：\*这不是斜体\*。

## 三、列表

**原文**：

```markdown
- 第一项
- 第二项
  - 嵌套一层
  - 再一个
- 第三项

1. 第一步
2. 第二步
   1. 子步骤
3. 第三步

- [x] 已经做完的
- [ ] 还没做的
```

**效果**：

- 第一项
- 第二项
  - 嵌套一层
  - 再一个
- 第三项

1. 第一步
2. 第二步
   1. 子步骤
3. 第三步

- [x] 已经做完的
- [ ] 还没做的

嵌套靠缩进，通常是两个空格。任务列表的方括号里 `x` 表示勾选。

## 五、代码块

**原文**：

````markdown
```js
function greet(name = "world") {
  return `Hello, ${name}!`;
}
```

```python
def greet(name: str = "world") -> str:
    return f"Hello, {name}!"
```

```
没有语言标注的代码块，等宽字体，不高亮
```
````

**效果**：

```js
function greet(name = "world") {
  return `Hello, ${name}!`;
}
```

```python
def greet(name: str = "world") -> str:
    return f"Hello, {name}!"
```

```
没有语言标注的代码块，等宽字体，不高亮
```

写源码的时候注意：如果内容本身包含三反引号，外层要用**四个**反引号包住，像上面那样。

代码块右上角有个「复制」按钮，点一下复制整段。

## 六、表格

**原文**：

```markdown
| 语法 | 说明 | 支持度 |
|------|------|--------|
| `# 标题` | 一到六级 | 全支持 |
| `**粗体**` | 加粗 | 全支持 |

| 左对齐 | 居中 | 右对齐 |
|:-------|:----:|-------:|
| a | b | c |
```

**效果**：

| 语法 | 说明 | 支持度 |
|------|------|--------|
| `# 标题` | 一到六级 | 全支持 |
| `**粗体**` | 加粗 | 全支持 |

| 左对齐 | 居中 | 右对齐 |
|:-------|:----:|-------:|
| a | b | c |
| 长一点的文字 | 中 | 123 |

第二行第二列那个冒号就是对齐标记，`:---` 左、`:--:` 居中、`---:` 右。

窄屏下表格可以左右滑动，不会撑破版面。

## 七、链接与图片

**原文**：

```markdown
行内链接：[GitHub](https://github.com)
带标题的链接：[GitHub Pages](https://pages.github.com "GitHub Pages 官网")
自动识别：<https://example.com>

![图片说明](./hello-markdown/rain.webp "鼠标悬停时显示的文字")
```

**效果**：

行内链接：[GitHub](https://github.com)
带标题的链接：[GitHub Pages](https://pages.github.com "GitHub Pages 官网")
自动识别：<https://example.com>

![图片说明](./hello-markdown/rain.webp "鼠标悬停时显示的文字")

图片路径的写法有讲究：图片放在和 md 同名的文件夹里，引用时要带上这层目录名（`./hello-markdown/`）。点一下图片可以放大看。

## 八、分割线

**原文**：

```markdown
上面是内容。

---

下面是另一段。

***
```

**效果**：

上面是内容。

---

下面是另一段。

***

三个以上的 `-` 或 `*` 都行，前后记得空一行，不然会被当成标题的下划线。
